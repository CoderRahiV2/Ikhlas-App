# ইখলাস – Netlify সেটআপ
1. এই ফোল্ডার GitHub-এ পুশ করে Netlify-তে "Import from Git" করুন (অথবা `netlify deploy --prod`)।
2. Site settings → Environment variables:
   - `ADMIN_PASSWORD` = আপনার অ্যাডমিন পাসওয়ার্ড
   - `GROUP_CODE` = ইখলাস গ্রুপের গোপন কোড (সদস্যদের দিন)
3. অ্যাডমিন প্যানেল: `https://your-site.netlify.app/admin.html`
